The game

One shared round

  1. ListenThe host device plays the preview through a shared speaker.
  2. AnswerEach player identifies the song and chooses the listeners.
  3. RevealAnswers stay private until the server advances the round.
  4. ScoreFrozen song and player facts determine the points and ranking.

The server owns the clock

A browser cannot extend a deadline by sending an old timestamp. Commands enter a room-specific lock, use server time, and apply due transitions before handling the next action.

Separate domains
Rooms manages membership and listening data. Game manages rounds, answers and rankings.
Stable scoring
A game freezes its roster and song facts at the start. Disconnects and later lobby changes do not rewrite an earlier round.
Recovery
Refreshing reconnects to the room. After a server restart, interrupted games are aborted and rooms return to the lobby.

Two ways to bring the music

Demo

A downloadable pack contains 100 song previews and simulated listening libraries. After setup, the demo works offline without a Spotify account.

Real

Spotify imports personal listening data through the same admission and game workflows. This mode needs configured provider access and approved participants. Personal Apple Music import is outside the current scope.

Tests at the boundaries

Controlled clocks and random inputs make rule tests repeatable. SQLite and HTTP tests cover persistence, authorization and answer privacy; browser-controller tests cover screen and audio behavior. Live provider access and multi-device audio have separate manual checks.
