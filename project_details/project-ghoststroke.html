Ghoststroke

Prepare text once, choose its cadence, then send it to the exact editable field you select. Ghoststroke keeps the writing plan local while preserving deliberate pauses, corrected mistakes, and your ability to stop.

Quick Type stays out of the way

Write or paste in the compact bottom panel, choose a saved cadence and line-break policy, then press Find Target & Start. A Shift-Option-click identifies the destination without making Ghoststroke guess.

  • Typing begins only after the same editable Accessibility element is observed twice.
  • The signed DMG is Apple-notarized, stapled, and accepted by Gatekeeper.

Availability: the release artifact is ready, but a public download location has not been published yet.

A controlled handoff

Compose, target, continue

01

Prepare in Quick Type

Enter the exact source, select a built-in or saved profile, and decide whether line breaks become spaces, Return, or Shift-Return.

02

Choose the real field

Start target selection, then Shift-Option-click the destination. Secure and non-editable fields are rejected before any key is emitted.

03

Type the generated plan

Extended grapheme clusters stay intact. Temporary mistakes and synonym slips are fully rolled back before the requested source text is committed.

04

Pause without starting over

Pause stops before the next uncommitted unit. Retargeting resumes from confirmed progress, while Stop remains available from the panel, menu bar, or shortcut.

Studio

Author the typing signature

  • Cadence with structure

    Tune pace, rhythm, thinking pauses, correction frequency, multi-letter mistakes, synonym slips, and advanced timing—then preview the actual generated plan locally.

  • Profiles, drafts, recovery

    Named profiles and composer drafts use versioned local JSON with atomic writes. Built-ins cannot be overwritten, and incompatible data is preserved for recovery.

  • Permissions are part of the product

    Setup explains Accessibility access, shortcut conflicts, storage recovery, line-break behavior, and optional Dock visibility instead of hiding system requirements.

Notarized does not mean universal

Version 1.0.0 build 10 is a signed, hardened-runtime Apple-silicon release whose stapled ticket and Gatekeeper assessment pass. It still requires Accessibility permission, and macOS cannot prove that every third-party editor accepted a synthetic event. Apps that reject those events remain unsupported; a public download URL is the remaining distribution step.
