Cross-device clipboard · 2024

ClipClop

Share text and images between a Mac and Android phone over local Wi-Fi.

Download Mac + Android ↗View source ↗
  • Python · Java
  • Working prototype

Pairing and reconnection

Pairing
Scan the Mac’s QR code to share its device identity and a fresh encryption key with Android.
Encrypted transport
Text and images travel over TCP. Each message uses AES-256-GCM with a fresh nonce.
Rediscovery
Bonjour/mDNS, a UDP beacon, and manual IP provide discovery options. The saved device ID lets the phone find its Mac after an IP address change.

Clipboard access

The Mac app checks NSPasteboard’s change counter and reads content only when it changes.

An Android foreground service receives clips and maintains the connection. Sending is user-triggered because Android restricts background clipboard reads.
