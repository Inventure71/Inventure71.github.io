Suggestions beside the cursor

ContextKey gathers text around the focused field, generates a continuation locally, and displays it beside the cursor for you to accept.

  • Accessibility APIs and optional Vision OCR cover native apps; a tiny browser extension feeds in structured DOM context.
  • MLX runs the model locally; Option-Space accepts the displayed suggestion.

Prototype pipeline

Capture, generate, filter, overlay

01

Capture

Grab the focused field, the text around it, which app I'm in, and any structure the browser can hand over.

02

Generate

Hand a compact prompt to a language model running locally through MLX.

03

Rank

Filter irrelevant, repetitive, or unsafe candidates; show nothing if none pass.

04

Overlay

Draw a faint inline suggestion, and only insert it when you actually accept with Option-Space.

When to suggest nothing

The ranker filters repeated text, irrelevant continuations, and unsafe suggestions. Context capture and the local transport still need further security work before the prototype is ready for wider use.
