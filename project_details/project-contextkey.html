macOS autocomplete · 2026

ContextKey

Autocomplete beside your cursor, using the current field and a model running on your Mac.

  • Swift · AppKit · MLX
  • Experimental prototype

Reading the current field

Native applications
Accessibility reads the focused field, surrounding text, and nearby labels. Optional Vision OCR adds text from the active window when needed.
Browser editors
A Chromium extension supplies DOM context for web editors that expose little text through Accessibility.
Local inference
MLX generates candidates locally. A filter rejects irrelevant or repeated continuations.

Displaying suggestions

An AppKit overlay shows the suggestion without taking focus. Acceptance is handled only while a suggestion is visible, and insertion preserves the clipboard.
