Project Snapshot

GenGame explores "Programmatic Evolution"—the concept of software that rewrites itself during runtime to adapt to player behavior or fix bugs autonomously.

  • Autonomous code patching using LLMs and Merge3.
  • Real-time state and code synchronization via WebSockets.

Core Pillars

The Engine of Evolution

  • Programmatic Evolution

    GenAI agents monitor game logs and performance, generating and applying code patches to the live environment without restarts.

  • Modular Architecture

    Every game mechanic, character ability, and UI element is a decoupled module, allowing the AI to surgical modify specific components.

  • Decentralized Sync

    Integrated Merge3 logic ensures that code patches generated on the server are merged and executed identically across all clients.

Beyond Fixed Mechanics

Traditionally, game rules are set in stone at launch. GenGame turns the "developer loop" into a "runtime loop," where the game itself acts as the developer, tester, and deployer.

The Evolution Cycle

How a Patch is Born

01
Diagnosis

The monitoring agent detects an imbalance or a bug in a specific character ability module.

02
Generation

An LLM agent writes a Python patch, tested against a simulated sandbox environment.

03
Synchronization

The patch is broadcast to all clients; Merge3 applies the changes to their local bytecode.

04
Hot-Reload

The game engine re-imports the modified module, updating mechanics for all players mid-session.
