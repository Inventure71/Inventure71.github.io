Narrative

Why this project exists

VictorIA emerged from exploring how AI techniques can unify strategic decision-making, vision-guided annotation, and physical actuation. The name blends "Victory" (game strategy) with "AI," reflecting a focus on intelligent systems that lead to successful outcomes across multiple domains—from winning games to processing cellular imagery to experimental robotic tasks. Rather than building one perfect solution, VictorIA serves as a testbed where perception and decision pipelines converge in applied AI scenarios.

Systems

What makes it different

Game AI Strategy

Connect 4 implementation with board representation, move validation, win detection, and AI agents using minimax or alpha-beta pruning for optimal strategic decisions.

Computer Vision Pipeline

Interactive point selection on images with GUI callbacks, ROI extraction, and processing of cell imagery from raw datasets to analyzed outputs.

Robotics Integration

Experimental robotic control that interfaces with devices (serial, USB, Bluetooth) or simulates movement, translating game states or image data to motion commands.

Flow

How the system operates

01
Data Acquisition

Load raw images from the Images/ or cells/ directories, or initialize a game board state for AI decision-making.

02
Processing & Analysis

Apply computer vision techniques for point selection and cell segmentation, or run game AI algorithms to evaluate optimal moves.

03
Action & Output

Store processed results in Processed_Cells/, display game decisions, or translate analytical outputs to experimental robotic commands.

Features

Key capabilities

Modular Architecture

Central orchestrator (main.py) coordinates mode selection between game, image processing, and robotics experiments with clear separation of concerns.

Interactive Vision Tools

ImagePointSelection.py provides GUI-based coordinate selection on images for manual annotation and ROI identification in cellular datasets.

Model Management

Models/ directory supports storage of trained ML models for classification, segmentation, or policy networks that enhance decision-making.

Utility Layer

Reusable helpers under utils/ prevent code duplication across game logic, image processing, and robotics modules.
