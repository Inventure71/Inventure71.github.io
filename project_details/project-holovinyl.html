Project Snapshot

HoloVinyl experiments with touchless interaction by pairing live hand tracking and lightweight object detection with a modular UI canvas.

  • Captures and interprets gestures at ~25 FPS on consumer hardware.
  • Builds buttons and submenus dynamically in response to tracked tasks.

Narrative

Why build a holographic deck

Traditional music controllers expect tactile hardware—knobs, buttons, or touchscreens that wear out and constrain performance. HoloVinyl flips the paradigm: by blending live hand landmarks with contextual object detection, it creates a hovering control surface that responds to motion alone. The project became a sandbox for mapping ML perception into vivid UX feedback, letting me design gestures, states, and latency budgets in unison.

  • Python 3.11
  • OpenCV Video Pipelines
  • Ultralytics YOLO nano weights
  • Modular UI composition

Systems

How the interface stays responsive

Signature Moment

Pinch to grab a floating vinyl, swipe to cue a track, and see menus reorganize instantly around your hand pose.

Perception Stack

HandTracking.py extracts 21 landmarks per frame while a nano YOLO head flags contextual objects that unlock alternate controls.

Dynamic UI Fabric

UI.py, addButtonUI.py, and submenu_UI.py render overlays directly onto the video texture, injecting buttons, meters, and tooltips on demand.

Extensibility Hooks

Pluggable models inside custom_models/ extend detection vocabularies without reworking gesture logic or the event dispatcher.

Flow

How a session plays out

01
Calibration

Webcam stream initializes, lighting is normalized, and gesture thresholds hydrate from config.

02
Perception Loop

Hand landmarks and YOLO detections stream into a shared state store that translates poses into intents.

03
UI Reaction

Dynamic buttons and vinyl widgets spawn, animate, and retire based on recognized gestures and detected props.

04
Playback Control

Mapped commands fire into the audio layer, logging interactions for future gesture analytics.
