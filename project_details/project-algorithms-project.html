Algorithm Suite

Engineered for Efficiency

BFS Pathfinding

Used in arena/utils/find_path_bfs.py to calculate optimal routes on the arena grid.

  • Time Complexity: O(V + E)
  • Space Complexity: O(V)
  • Supports dynamic obstacle avoidance and neighbor validation.

Merge Sort

Custom merge_sort_by_key implementation in core/sorting.py for handling troop data.

  • Time Complexity: O(n log n) (consistent performance).
  • Space Complexity: O(n)
  • Ensures stable and predictable data organization.

Linear Search

Reliable linear_search in core/linear_search.py for targeted element retrieval.

  • Time Complexity: O(n)
  • Space Complexity: O(1)
  • Used for selecting targets in dynamic troop collections.
