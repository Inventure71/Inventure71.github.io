Cross-platform systems · 2026

Project Unity

One keyboard and mouse across a Mac and Windows PC. Cross a screen edge to change computers.

  • Swift · C++ / Win32
  • Mac–Windows prototype

Pairing and input control

Pairing
DNS-SD discovers nearby computers. A six-digit confirmation pairs them; manual addressing is available if discovery fails.
Transport
Authenticated TCP assigns input ownership. Encrypted UDP carries cumulative motion and key/button snapshots so a lost packet need not stall movement.
Recovery
Acknowledgements track key and button changes. Watchdogs release remote input if the connection fails.

Input latency

Measurements cover transport and input injection. Application rendering time is excluded.

Same-LAN transport
20,000 samples at 1,000 Hz with no recorded packet loss. The Wi-Fi tests measured a 2.0 ms median round trip and 6.1–7.0 ms at p99.9.
Capture to injection
1.107 ms median and 2.481 ms p99.9 across 5,001 segmented motion samples.
