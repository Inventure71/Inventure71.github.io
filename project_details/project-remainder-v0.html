Context

Why weave reminders into knowledge

The project started with a simple itch: raw reminders and notes lack structure, context, and longevity. Across multiple repositories I explored how Gemini-powered enrichment, normalization pipelines, and modular UI layers could turn snippets into a living personal knowledge graph. Each iteration pushed the architecture forward—from a single Python file handling everything to a stack where capture, enrichment, presentation, and analytics are split into collaborative services.

  • Capture surfaces

    Desktop, web, and clipboard tools share contracts so every snippet lands with consistent metadata.

  • Knowledge threads

    Semantic clustering stitches reminders into storylines that resurface when projects reappear.

  • Human override

    Curated editing panes let me correct AI enrichment or pin insights without breaking automation.

Concept Pillars

Core ideas that persist across versions

Reminder capture

Desktop, web, and clipboard entry points funnel into a common schema tagged with source, timestamp, and context.

  • Normalization layer deduplicates and preserves raw text for audits.
  • Capture endpoints share validation to avoid drift.

AI enrichment

Gemini templates clean text, infer tags, surface due dates, and recommend follow-up actions.

  • Fallback heuristics keep the pipeline flowing if AI confidence dips.
  • Structured JSON responses feed analytics and UI highlights.

Context weaving

Reminders link to projects, people, and timelines so knowledge feels navigable rather than linear.

  • Semantic clustering surfaces related work streams automatically.
  • Manual anchors let me curate narrative arcs across notes.

Iterative architecture

Each repository evolves the stack—from monolith to modular services—without losing data continuity.

  • Shared contracts keep capture and presentation layers interchangeable.
  • Versioning strategy documents migrations between repos.

Reminder DNA feeds every new surface

Experiments stay compatible because each repo honors the same capture schema. That lets analytics, enrichment, and UI layers remix history without migration headaches.

Architecture

How the system hangs together

Capture Layer

Desktop UI, web forms, or clipboard monitors push reminders into a normalized ingestion queue.

Enrichment Service

Gemini prompt templates clean text, infer tags, compute metadata, and return structured JSON blobs.

Persistence & Ledger

SQLite/PostgreSQL stores raw, cleaned, enriched versions alongside audit trails and lineage references.

Presentation

pywebview hybrid shell (RemainderV0) and decoupled JS front-end (ProjectLoom) render timelines, filters, and AI suggestions.

Analytics & Feedback

Pandas jobs produce retention metrics, enrichment acceptance rates, and tag distributions to steer future releases.

Configuration & Settings

JSON settings and environment overrides tune AI prompts, clipboard thresholds, and integration credentials.

Flow

How a reminder becomes knowledge

01
Capture

User adds a reminder via desktop quick-add, clipboard trigger, or web form; payload lands in the ingestion queue.

02
Normalize

Cleaning scripts strip noise, unify dates, and prepare a structured prompt for Gemini.

03
Enrich

Gemini returns enriched text, suggested tags, timeline hints, and semantic labels; they are merged into the reminder record.

04
Weave

UI layers display linked reminders, evolution history, and AI suggestions. Users confirm or adjust, feeding metrics back into the system.
