ReminderZ & Project Loom

Two prototypes for organizing messages and building Python programs visually.

  • Python · Gemini · Electron · FAISS
  • Solo development

01 / ReminderZ

Message organization

Gemini organizes Telegram and WhatsApp notes-to-self into projects and reminders. Answers link back to their source messages.

02 / Project Loom

Visual programming

Connect execution and value pins in an Electron editor. The compiler walks the graph from BeginPlay to generate Python, with function blocks drawn from existing modules.

Search and UI generation

Local retrieval
Loom uses FAISS and local EmbeddingGemma embeddings to retrieve documents by meaning.
UI generation
Shape and aspect-ratio rules turn drawn rectangles and circles into UI components.
