Evolve Project

An experimental agent that can run shell commands, write new Python tools, and load them during a task.

Python Gemini Autonomous agents
Role Solo builder · Prompt architect
Timeline 2025
Stack Python · Gemini · Ollama
Status Research prototype

Tools that change during a run

An agent loop sends context to the model, executes tool calls, and returns their output. New Python tools written during the task become available on the next turn.

  • Dynamic tools — the agent writes Python into tools/ and importlib reloads it, no restart.
  • It has real shell access, and can read back its own terminal output as just another tool.

The ideas behind it

Agent behavior

  • Repeated tool calls

    Each turn it sends its context to Gemini, runs whatever tool calls come back, feeds the output in, and repeats — until it decides it's done and emits a stop token.

  • Tools it writes itself

    New abilities aren't hard-coded. The agent drops a Python file into tools/ and the handler discovers and reloads it, so its toolbox grows while it runs.

  • Prompt experiment

    The experimental prompt encourages the agent to create external memory and break tasks into steps.

Under the hood

How it's put together

The agent loop

A handler runs the conversation, executes the model's function calls, keeps a rolling window of recent responses, and halts on a sentinel token.

  • Retry logic tells a 503 "overloaded" from a 429 "quota" and honors the API's own suggested delay.
  • Rate-limited to stay inside Gemini's request budget.

Self-written tooling

A reflection-based registry imports every function it finds in tools/ and hands them to the model — including files the agent just created.

  • importlib.reload means no restart to pick up new tools.
  • Ships with shell execution and a log reader out of the box.

Gemini and Ollama backends

Besides Gemini, an experimental backend routes the same loop through local models via Ollama, hand-rolling docstring-to-JSON-schema conversion.

  • Tried against llama 3.1, mistral-nemo, and phi3.
  • A planned review agent has not been integrated.

The research question

This prototype explores how an agent manages an open-ended task when it can extend its own tools. The experiment focuses on tool creation, context management, and the points where the loop needs intervention.

Flow

How a single turn works

01

Prompt

The agent gathers its task and current context and sends the whole thing to Gemini.

02

Act

Gemini answers with tool calls — run a command, read the log, or write an entirely new tool.

03

Reload

If it wrote a new tool, the handler hot-reloads tools/ so it's callable on the very next turn.

04

Loop

The results feed back in and the cycle repeats — until the agent decides it's finished.
