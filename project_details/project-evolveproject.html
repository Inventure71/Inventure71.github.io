Project Snapshot

EvolveProject replaces static card libraries with prompt-driven generation: every pack opening requests bespoke mechanics, flavor, and balance metadata.

  • Procedurally generates infinite, lineage-aware cards without pre-authored sets.
  • Validation layer clamps power levels and filters exploit-prone combos before they reach players.

Creative loops

How the generator feeds designers

  • Designer prompts

    Writers tweak archetype blueprints and immediately preview how new mechanics remix rarity curves.

  • Meta snapshots

    Telemetry dashboards reveal which factions dominate so balance knobs can be nudged without full patches.

  • Player expression

    Custom events let players request themes, mascots, and rule twists that still arrive as validated card JSON.

Generator spine

Safeguards around every new card

Template vault

Prompt blueprints define mechanical knobs, rarity weights, and lore tone so outputs feel intentional.

  • Archetype configs tweak stat curves based on live telemetry.
  • Flavor slots let writers inject seasonal stories on demand.

Gemini orchestration

Request broker replays failed generations with patched JSON or fallback prompts before Unreal hears about it.

  • Structured diffing ensures stat blocks stay machine readable.
  • Rate limiting keeps the pipeline stable during release spikes.

Balance watchtower

Heuristics grade cards against banned mechanics and power ceilings, logging every veto for designers.

  • Telemetry feedback loops clamp runaway archetypes.
  • Manual approvals can override but must cite a rationale.

Live ops without content crunch

Designers focus on new mechanics while the generator handles balanced variants. Players feel endless novelty without waiting months for expansion packs.

Flow

How a card comes to life

01
Trigger

Unreal Engine signals a pack opening or evolution event with desired rarity and archetype hints.

02
Generate

The backend fills a prompt template, calls Gemini, and receives structured card data + narrative flavor.

03
Validate

Rule filters clamp power creep, assign rarity, and flag risky mechanics for re-roll if needed.

04
Deliver & Evolve

Card JSON streams back to Unreal; gameplay telemetry later tunes prompts for the next generation.
