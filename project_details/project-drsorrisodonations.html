Dr Sorriso Donations

An internal tool for Fondazione Dottor Sorriso that extracts donor names from bank-transfer descriptions and records donations in the charity’s platform.

Python Selenium GPT-4o-mini
Role Solo builder
Timeline 2024 – 2025
Stack Python · Selenium · GPT-4o-mini
Status Internal tool

From a transfer to a donation record

The tool reads transfer descriptions, identifies donor names or campaign codes, and matches entries to existing contacts or creates a contact when needed.

  • A multi-call LLM consensus — it asks GPT-4o-mini a few times at different temperatures, then votes on the donor's name.
  • Italian first-name and surname dictionaries help distinguish donor names from bank codes.

Donation processing

Identify, match, and record

  • Two kinds of donation

    Some transfers carry a campaign code buried in the text; others just have a name. The bot detects which, and routes each down the right path.

  • Donor extraction

    It strips transaction boilerplate, dedups repeated tokens, and cross-checks against a dictionary of Italian names to pull the real donor out.

  • Cached results

    Parsed results are cached to avoid repeating language-model calls for descriptions already processed.

Under the hood

Reading, naming, filing

Reading the memo

Italian SEPA transfers are full of noise — TRN codes, "EROGAZIONE LIBERALE", bank BIC codes. A hand-built blacklist and regex strip it back to the essentials.

  • Four fallback regex patterns pull out campaign and donor codes.
  • Whatever's left goes to the language model.

Naming the donor

GPT-4o-mini identifies the first and last names, with domain rules baked in — names are Italian, and never two surnames in a row.

  • A few calls at different temperatures, then a consensus vote.
  • A second pass checks the extracted name.

Filing it away

Selenium drives the real donation platform — selecting campaigns, matching contacts, creating new ones, and confirming each entry.

  • Handles error popups, alerts, and a self-migrating local cache.
  • Reuses cached donor-parsing results.

Built for the foundation

The tool supports donation administration at Fondazione Dottor Sorriso by automating donor lookup and entry from bank-transfer descriptions.

Flow

How one donation gets filed

01

Read

Log into the donation platform and pull the next transfer's raw bank description.

02

Decide

Is there a campaign code hidden in the text, or just a name? Route it down the right path.

03

Extract

Regex pulls the code, or the LLM — with a consensus vote — pulls the donor's name out of the noise.

04

File

Match the campaign or contact, create one if it's missing, confirm the entry, and cache the result.
