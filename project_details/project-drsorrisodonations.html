Fondazione Dottor Sorriso · Internal tool

Dr Sorriso Donations

Match bank transfers to donors and enter donations in the foundation’s existing platform.

  • Solo project
  • March 2023–February 2025
  • Python · Selenium

Less time on manual entry

Processed more than 1,000 inconsistent donation records. The automation reduced manual data entry by 90%, saving the team an estimated 40 hours of administrative work per month.

Identifying the donor

Clean the description
Rules remove SEPA boilerplate, banking identifiers, and repeated tokens. Italian name dictionaries help distinguish names from codes.
Resolve the donor
GPT-4o-mini proposes names across several calls. Agreement and a second pass check the result; a cache avoids parsing the same description again.
Enter the record
Selenium selects the campaign, finds or creates the contact, and enters the donation in the existing platform.
