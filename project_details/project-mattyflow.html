MattyFlow

Hold Fn, speak naturally, and keep working: MattyFlow transcribes on-device, rewrites the rough transcript with a local Gemma pipeline, and inserts the finished text into the app you were already using.

A complete local loop, not a dictation API demo

The menu-bar app owns the gesture, permissions, microphone, backend lifecycle, request ordering, history, and paste destination. A private local service owns models and turns audio into finished text.

  • Speech recognition and rewriting stay on the Mac by default; OpenAI is an explicit optional provider.
  • Model selection, prompt caches, downloads, and idle RAM unloading are managed as product state.

The production path

Capture, understand, insert

The Mac owns the interaction

A native menu-bar app monitors Fn, records audio, preserves the previously focused application, supervises the backend, and pastes only the newest completed request.

The service owns transcription

FastAPI normalizes the recording and routes it through the selected local speech model. Model catalogs make installation and activation explicit instead of hiding downloads.

Gemma cleans the result

The transcript can pass through local rewrite or advanced-rewrite prompts before insertion. Direct text requests use a separate agent endpoint so dictation and assistant behavior stay distinct.

Private by default still has a cost

The working path requires Apple Silicon plus Microphone, Input Monitoring, and Accessibility permission. Model weights download separately rather than bloating the app, and a cold first request can take longer while local runtimes load. The project remains an active prototype rather than a public release.
