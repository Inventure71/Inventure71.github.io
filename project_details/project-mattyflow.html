Dictation for macOS

MattyFlow

Hold Fn to dictate into your current app. MattyFlow transcribes your speech and can rewrite the result using models running on your Mac.

Active macOS prototype

From microphone to text

The menu-bar app records speech and returns the result to the previously focused app. A local service handles transcription and optional rewriting.

  • Speech recognition and rewriting stay on the Mac by default; OpenAI is an explicit optional provider.
  • Choose and download local models; idle models can be unloaded to release memory.

Dictation pipeline

Capture, understand, insert

Recording and insertion

A native menu-bar app monitors Fn, records audio, preserves the previously focused application, supervises the backend, and pastes only the newest completed request.

Local transcription

FastAPI normalizes the recording and routes it through the selected local speech model. The model catalog lists installation and activation options.

Optional rewriting

The transcript can pass through local rewrite or advanced-rewrite prompts before insertion. Direct text requests use a separate agent endpoint so dictation and assistant behavior stay distinct.

Requirements

The prototype requires Apple silicon and Microphone, Input Monitoring, and Accessibility permissions. Models download separately, and the first request can take longer while they load. A public release is not available yet.
