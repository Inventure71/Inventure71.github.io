Noty

Most note apps remember what you wrote but forget where you were. Noty is a local-first Markdown sticky-note app whose notes can latch onto a specific window — your editor, a browser tab, a Finder folder — and follow it around the desktop.

Why it exists

Notes keep content but lose context. Noty keeps both — a note can float free, or attach to the exact window where the thought belongs, hide when that window goes away, and quietly reappear the moment it comes back.

  • Attached notes shadow their host window instead of piling up as desktop clutter.
  • Everything — notes and attachment state — lives locally in SQLite. No cloud, no account.

The loop

Write it, pin it, find it again

  • Markdown that gets out of the way

    Small, focused note windows with live preview, checklists, and code blocks — light to write in, but still real Markdown underneath.

  • Notes that know their window

    Instead of storing fragile window IDs, Noty matches on durable app keys — a VS Code workspace, an Arc tab's UUID — so a note finds the right window again even after a restart.

  • A cowboy that wrangles them

    An animated mascotte rounds up parked notes so you can scout, corral, and recall them — without turning the desktop into a dashboard.

Not another cloud notebook

I wasn't trying to build somewhere else to store notes — I was trying to make notes behave like part of the desktop. Everything stays on the Mac, and most of the real work went into the unglamorous stuff: matching windows reliably, following them without stealing focus, and never losing a note when something goes wrong.
