Neural Noir

AI-Driven Interactive Story Game

Neural Noir is an interactive game that generates unique murder-mystery narratives using AI, providing players with an immersive storytelling experience.

Functionality:

  • Dynamic Story Generation: Uses AI to create diverse and unpredictable storylines, ensuring a unique experience each time.
  • Character Development: Generates distinct characters with individual backstories and motives.
  • Player Interaction: Allows players to influence the narrative through their choices, leading to multiple possible outcomes.

Technical Implementation:

  • Game Engine: Built using Unreal Engine, leveraging its capabilities for immersive graphics and gameplay.
  • AI Integration: Utilizes AI models to generate story elements and character dialogues dynamically.
  • Scripting: Employs Python for scripting game logic and integrating AI-generated content.

Skills Demonstrated:

  • Expertise in game development and AI integration.
  • Creative storytelling and narrative design.
  • Proficiency in Unreal Engine and Python scripting.
